# Tóm tắt RTOS_report.docx

Nguồn local: C:/RTOS/RTOS_report.docx. Báo cáo thuộc môn Hệ điều hành thời gian thực, RTOS345264_02, học kỳ 2 – đợt 1 năm 2025–2026; nhóm ghi “Thứ 3,5 tiết 1–4”; giảng viên ThS. Huỳnh Hoàng Hà. Bìa tháng 3/2026.

Thành viên: Phạm Ngọc Duy, Hà Quang Huy, Lê Đoàn Thái Khương, Võ Trung Nguyên. Không suy ra phân công cá nhân từ thứ tự danh sách. Mã số sinh viên không đưa vào bản trình bày công khai.

| Chương | Nội dung trong tài liệu |
| --- | --- |
| 1 | Mục tiêu RTOS; ESP32, LED, nút, BH1750, OLED |
| 2 | Task/scheduling, semaphore và TCP |
| 3 | Sơ đồ hệ thống, kết nối và thiết kế GUI Qt |
| 4 | Arduino/PlatformIO, code Non-OS, mô tả OS/server/client |
| 5 | Có tiêu đề phân tích kết quả nhưng chưa có nội dung đánh giá |
| 6 | Có tiêu đề kết luận/hướng phát triển nhưng chưa có nội dung |

Phần Non-OS mục 4.2.2 có khối code đủ setup/loop đã khôi phục. Phần code OS trong báo cáo chưa có khối đầy đủ tương ứng, nhưng firmware thực tế còn lưu ở OS_Project. Client UI có tên đủ bốn thành viên khớp bìa báo cáo.

Repository không tuyên bố có số liệu latency, jitter, độ ổn định hay video thực nghiệm khi tài liệu chưa cung cấp. Các sơ đồ được lấy từ file ảnh còn lưu; ảnh GUI được dựng từ mã UI hiện có, chưa kết nối hệ thống.

Mã tham khảo MPU6050/Firestore trên GitHub là phiên bản khác báo cáo BH1750/TCP của nhóm. Phân biệt nguồn tại PROVENANCE.md.
